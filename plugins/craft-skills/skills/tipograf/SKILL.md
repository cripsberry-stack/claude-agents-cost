# /tipograf

Расставляет русскую типографику: ёлочки `«…»`, вложенные лапки `„…“`, длинные тире `—`,
неразрывные пробелы после предлогов и в сокращениях, `×` вместо `x`, `…` вместо `...`.

Движок детерминированный — это скрипт, а не языковая модель. Одинаковый вход даёт
одинаковый выход, повторный прогон ничего не меняет.

## Использование

```bash
node <папка навыка>/tipograf-cli.mjs <файл>...    # применить и записать
node <папка навыка>/tipograf-cli.mjs --check <файл>...  # проверить, не записывая
echo 'текст' | node <папка навыка>/tipograf-cli.mjs --stdin
node <папка навыка>/tipograf-cli.mjs --rules       # список правил
```

Флаги:

| Флаг | Что делает |
|---|---|
| `--check` | Не пишет файлы. Выходит с кодом 1, если правки нужны. Для CI и pre-commit. |
| `--stdin` | Читает stdin, пишет в stdout. |
| `--off id,id` | Выключить правила (`--off nb-short,hyphen-hard`). |
| `--on id,id` | Включить выключенные по умолчанию (`--on fractions,degree,numero`). |
| `--rules` | Показать все 32 правила: `[×]` — включено по умолчанию. |
| `--quiet` | Только изменённые файлы, без итогов. |

Glob поддерживается: `'src/**/*.md'` (в кавычках, чтобы шелл не раскрыл сам).

## Как действовать

1. **Уточни охват, если он неочевиден.** «Причеши текст» в репозитории со статьями — это
   какие файлы? Один открытый или все `content/**/*.md`? Спроси, если не ясно.

2. **Сначала `--check`, потом запись.** Покажи пользователю, сколько правок и в каких файлах,
   и только затем применяй. Это необратимая правка чужого текста — не молчаливая.

3. **Проверь результат.** После записи прогони `git diff` и покажи характерные места.
   Если правок сотни, покажи 5–10 показательных, а не весь дифф.

4. **Не типографь то, что не проза.** Расширения `.md`, `.mdx`, `.markdown` защищаются
   автоматически. Для `.txt`, `.html`, `.astro`, `.vue` защиты нет — там либо не применяй,
   либо сначала убедись, что в файле нет кода и атрибутов с прямыми кавычками.

5. **Уважай отключённые правила.** По умолчанию выключены `fractions` (½), `degree` (°C),
   `numero` (№), `minus` (−), `nb-thousand` (1 000 000), `bullets` (•), `dup-punct`, `upper-after`.
   Они меняют смысл или ломают код/артикулы чаще, чем помогают. Включай осознанно.

## Что защищено в Markdown

Не трогаются: frontmatter, fenced-блоки ` ``` ` и `~~~`, код с отступом в 4 пробела,
inline-код `` `так` ``, `[текст](ссылка)`, HTML-теги, голые URL.

## Границы

- Только русский. Английский текст получит ёлочки — это неверно, для него отключи `quotes`.
- Правило `nb-abbr` намеренно привязывает сокращение к следующему слову
  («г. Москва» не разорвётся), даже когда сокращение завершает оборот.
- Есть веб-версия с подсветкой каждой правки: <https://tipograf.uspeshnyy.ru/>

## Правила движка

32 правила в пяти группах: Кавычки, Тире и дефисы, Пробелы, Знаки, Пунктуация.
Полный список с примерами — `--rules`. Логика — в `tipograf.js`;
это единственный источник правды, его же грузит сайт.
